1. End-to-End Carrier System Topology

FiberOps v4.0 cleanly decouples user-facing real-time workflows from high-latency telecom hardware I/O. HTTP webhooks and mobile requests validate, lock state atomically in MySQL, and enqueue resilient background jobs that speak directly to each tenant's encrypted MikroTik and OLT drivers.

2. Strict Row-Level Multi-Tenant SaaS & 5-Role RBAC

Every ISP tenant operates inside an isolated logical boundary enforced at both HTTP middleware and Eloquent Global Scope layers. Subscribers, GIS nodes (OLT/ODC/ODP), work orders, warehouse BOM materials, payment records, and technician GPS breadcrumbs are permanently partitioned by tenant_id.

3. Active Network Orchestrator: MikroTik RouterOS v7 & OLT/GenieACS

Benteng Siber bridges field labor directly to live network state via pluggable, SSRF-protected driver interfaces—eliminating manual Winbox CLI edits and WhatsApp back-and-forth with NOC staff:

  • MikroTik RouterOS v7 REST Driver (MikrotikRestDriver): Provisions PPPoE secrets on new FTTH installs, isolates overdue subscribers into the ISOLIR profile, and restores original bandwidth profiles automatically upon settlement.
  • OLT / GenieACS TR-069 Optical Gate (GenieAcsDriver): Queries live ONT Rx optical attenuation (-dBm) from ACS/OLT hardware. Sub-standard fiber splices (e.g., worse than -27.0 dBm) trigger immediate QA flags prior to completion.
  • Simulator & Production Drivers: Each tenant can verify end-to-end workflows in safe Simulator Mode before toggling Production RouterOS REST / GenieACS credentials inside encrypted tenant settings.

4. On-Site Dynamic QRIS & Async Queue Architecture

On-site cash collection leaks ISP revenue and delays service restoration. Benteng Siber embeds live Dynamic QRIS inside both the Technician PWA and Admin Console—backed by asynchronous queue workers so external routers never stall payment callbacks.

01

On-Site QRIS Invoice Creation

Technician taps Generate QRIS inside the work order. The API uses the tenant's AES-256 decrypted Midtrans key to mint a dynamic invoice QR code displayed on the technician's device.

02

Rate-Limited Signed Webhook (< 150 ms)

The subscriber pays via any QRIS e-wallet or bank app. Benteng Siber verifies the cryptographic signature and exact gross_amount, marks the invoice settled atomically, and responds HTTP 200 in under 150 ms.

03

Resilient Background Execution (ShouldQueue)

UnIsolateCustomerOnPaymentJob runs asynchronously (tries=3, exponential backoff 5s / 30s / 120s), calling MikroTik RouterOS REST to restore PPPoE access even if the ISP router experiences transient packet loss.

04

3-Second Live Sync to Mobile & NOC

Both Technician PWA and NOC Dashboard reflect PAID & ACTIVE within seconds and embed the payment settlement reference straight into the SHA-256 BAST certificate.

5. Deterministic Work Order FSM & Atomic BOM Concurrency

Tickets move strictly through server-enforced transitions: pending → assigned → en_route → in_progress → completed (with controlled rework or cancelled branches).

Pessimistic Row-Level Concurrency: Warehouse BOM deductions (drop-core cable, ONTs, patch cords) and ODP port occupancy increments execute inside MySQL transactions using lockForUpdate(). Concurrent mobile syncs can never oversell an ODP port or produce negative stock balances.

6. Certified Public BAST Cryptographic Payload

7. Offline-First Technician PWA & Android APK Sync

Built on Ionic 8, Angular 20, and Capacitor 8, the field app is engineered for zero-signal basements and rural splice enclosures:

  • FIFO Idempotent Queue: Offline status changes, BOM consumption, and photo uploads attach unique X-Idempotency-Key headers so cellular retries never create duplicates.
  • Batch GPS Flushing: Coordinates cache locally and flush to /api/location/batch automatically once signal returns.
  • 3-Second Lightweight Sync Signal: Compact delta polling keeps dispatch status, QRIS settlement confirmation, and new assignments instant without draining battery.
