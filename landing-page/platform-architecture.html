1. 4-Tier End-to-End Carrier System Topology

FiberOps v4.0 strictly separates real-time human workflows from high-latency telecom hardware I/O. Every mobile tap, admin dispatch, and payment callback passes through Zero-Trust tenant resolution, atomic Cache::lock idempotency, and MySQL row locks before delegating router and ACS calls to resilient ShouldQueue workers.

3. Multi-Router POP Fleet & OLT/GenieACS Hardware Orchestrator

Regional ISPs rarely run a single router. FiberOps v4.0 includes a dedicated Multi-Router POP Fleet architecture (tenant_routers) plus live optical telemetry verification—replacing manual Winbox edits and unverified field installations:

MIKROTIK ROUTEROS v7 REST FLEET

Multi-POP Router Orchestration

Register unlimited district POP routers with per-router isolation profiles (e.g., ISOLIR), automatic default failover promotion, and 1-click live connectivity tests.

  • AES-256 Encrypted Passwords: Decrypted only in memory inside queue workers.
  • SSRF Perimeter Guard: Blocks loopback (127.0.0.1, ::1) and cloud metadata (169.254.169.254) hosts.
  • 1-Click PPPoE Sync & CSV Import: Pulls up to 500 active/isolated PPPoE secrets directly from RouterOS or auto-detects comma (,) and semicolon (;) CSV files.
OLT & GENIEACS TR-069 GATE

Strict Optical Power (-dBm) Enforcement

Before a technician can close an FTTH activation or LOS outage ticket, OltService verifies real-time ONT health directly against the tenant's ACS/OLT controller.

  • Zero Silent Bypass: If OLT gate is enabled and a task links a subscriber or ODP node without an ont_serial_number, completion fails closed with HTTP 422.
  • Attenuation Threshold: Rejects poor fiber splices worse than the configured ceiling (default -27.0 dBm) or offline ONTs.
  • Permanent Seal: Live Rx/Tx dBm readings are stamped onto the task and embedded in the SHA-256 BAST certificate.

4. Global Payment Gateway Orchestration (Stripe USD + Midtrans QRIS)

FiberOps v4.0 eliminates field cash leakage for both global USD/EUR/GBP/AUD ISPs and Indonesian IDR ISPs via a pluggable, provider-locked payment architecture:

Stripe Checkout (Cards, Apple Pay, Google Pay, Link) Midtrans Core API (Dynamic QRIS) Zero-Config Simulator Mode Currency-Aware Min Validation (USD $1 / IDR 1,000)
01

Currency-Aware On-Site Invoice Generation

Technician or NOC generates a live payment link/QR in the tenant's currency (USD, EUR, GBP, AUD, or IDR). StripePaymentDriver applies official Stripe minor-unit rules (two-decimal vs. zero-decimal currencies) with zero external SDK bloat.

02

Provider-Locked Cryptographic Webhook (< 150 ms)

/api/webhooks/stripe verifies HMAC-SHA256 Stripe-Signature (with 5-minute replay guard) strictly against StripePaymentDriver; /api/webhooks/payment locks verification to each transaction's original provider (Midtrans SHA-512 vs. Simulator)—blocking cross-driver forgery even if settings change mid-flight.

03

Atomic Settlement & Async MikroTik Auto-Unblock

Inside a row-locked DB transaction (lockForUpdate()), exact gross_amount is validated, status flips to paid idempotently, and UnIsolateCustomerOnPaymentJob dispatches afterCommit() with tries=3 exponential backoff (5s / 30s / 120s).

04

3-Second Live Sync + Customer Receipt Notification

The technician's PWA (with bounded, tab-visibility-aware polling) and NOC Live Pulse flip to PAID & ACTIVE automatically while sending payment confirmation to the subscriber.

5. Deterministic Work Order FSM & Atomic Concurrency Engine

Work orders cannot jump randomly between statuses. Every transition executes inside TaskStateMachine::transition() under pessimistic row locking (Task::lockForUpdate()), appending an immutable entry to task_status_histories:

pending Intake / Queue
→
assigned Tech Dispatched
→
accepted Tech Confirmed
→
on-going Geofence Checked
→
completed BAST SHA-256 Sealed
rejected Declined / Re-queued
Admin Override Guard: Portal staff can reopen or override transitions only with an explicit audit reason, automatically resealing BAST & rolling back ODP ports atomically.
3 Concurrency & Boundary Hardening Guarantees:
  • Atomic Cache::lock Idempotency Middleware: Serializes simultaneous < 50ms double-taps sharing the same Idempotency-Key per tenant/user/path and replays cached 2xx responses with X-Idempotent-Replay: true.
  • Pessimistic BOM & ODP Locking: Warehouse material deductions and ODP port increments run inside lockForUpdate() transactions—preventing negative stock or double-booked ODP ports.
  • Equator & Prime Meridian Exact Coordinates: Geofence validation uses strict null checks (latitude === null) so sites at 0.0° (Indonesia, Kenya, Ecuador, Brazil) enforce GPS radius checks reliably.

7. Hybrid Mobile GPS & Zero-Loss Offline-First Sync Engine

Built with Ionic 8, Angular 20, and Capacitor 8, the Technician PWA & Android APK is built to survive basements, rural FTTH enclosures, indoor concrete buildings, and spotty 3G/4G towers without dropping field evidence:

STAGE 1 • SATELLITE

High-Accuracy GPS Lock

Requests hardware GNSS fix (enableHighAccuracy: true, 8s timeout) for precise pole/ODP coordinates and geofence verification.

STAGE 2 • AUTO FALLBACK

Wi-Fi & Cell Network Location

Indoors or on desktop browsers where satellite times out, automatically falls back to network triangulation (accepting up to 10km with honest indoor accuracy badges).

STAGE 3 • SANDBOX READY

Smooth Demo Mode Telemetry

In evaluation mode (?demo=1), synthesizes realistic live coordinates when no sensor exists so live prospect demos never flash false GPS errors.

  • Mutex-Locked FIFO Offline Queue (flushOfflinePromise): Compresses field proof photos via HTML5 Canvas, persists accept/start/progress/proof/BOM/signature/complete mutations locally with UUIDv4 Idempotency-Keys, and coalesces reconnect triggers so zero duplicate uploads occur.
  • Zero Data Loss on Auth/Throttle (401/403/408/429): Offline work orders are never discarded if a Sanctum token expires or a server rate-limits during a long underground shift—queue replay simply pauses safely until re-authentication.
  • True 2-Way Manual Sync & Battery Discipline: Manual Sync flushes pending offline mutations + buffered GPS first before pulling fresh dispatches; background polling pauses automatically when document.hidden is true, and Web Audio alert contexts close cleanly via osc.onended.
